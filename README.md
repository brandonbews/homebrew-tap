# homebrew-tap

Brandon Bews's [Homebrew](https://brew.sh) tap.

## EasyVox

[EasyVox](https://easyvox.dev) runs on Apple silicon Macs with macOS 26 or later. To install it:

```sh
brew install --cask brandonbews/tap/easyvox
```

The cask installs the DMG from [EasyVox's GitHub releases](https://github.com/brandonbews/easyvox/releases). `brew upgrade` installs new versions.
